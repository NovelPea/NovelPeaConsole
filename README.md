# NovelPea Console Edition

NovelPea Console Edition is a controller-friendly version of the NovelPea writing studio, designed for use on a TV with a game controller. It includes a chapter editor, story-planning tools, profile settings, and a guided introduction for new accounts.

## Features

Navigate the interface with a compatible game controller
Use the D-pad or left stick to move focus
Use A / Cross to activate a focused control
Use B / Circle to close the navigation menu or dismiss the tutorial
Use the controller’s Menu / Options button to open navigation
Write and organize chapters with automatic saving
Track chapter and word counts
Keep story details in the Story Bible, Characters, Places, and Notes sections
Export your manuscript as a .txt file where supported
Switch between light and dark themes

## Getting started

Save the app’s HTML as index.html.
Open it in a supported browser or approved console app environment.
Connect a compatible controller.
Create an account or log in.

Console availability depends on the platform. This HTML file alone does not install NovelPea on Xbox or PlayStation. Console distribution may require platform-specific packaging, developer access, and approval. Controller and browser support can vary by console.
Saving and privacy
This demo stores account and writing data in browser storage on the device. Data may not sync between devices, and clearing browser storage may delete it. The demo does not use a secure server, so do not enter real passwords or sensitive personal information.
